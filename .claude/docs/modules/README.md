# Module Docs

One markdown file per shipped module: `<nn>-<module>.md` (e.g. `02-product-catalog.md`). Written at step 7 of `/module-build` using the template in `/module-ship`.

Each captures: what was built, design source, **decisions on ambiguity**, **agent mistakes caught & corrected**, how it was verified, tests added, and data-integrity/security notes. These feed directly into the final `NOTES.md` at submission and are part of how the assessment scores supervision, verification, and handling ambiguity.

Order mirrors `../../MODULES.md`.
